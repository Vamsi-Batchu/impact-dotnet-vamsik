# Day5

This folder contains the runnable solutions for the tasks assigned to Day5.

## Run

From this folder:

```bash
dotnet run
```

Each task is a separate `.cs` file with its own `Program` class. To avoid multiple entry points,
run one task at a time by temporarily excluding the other task files, or use the task-specific
projects generated in the `TaskProjects` folder.

The source files are intentionally kept simple and beginner-friendly.
